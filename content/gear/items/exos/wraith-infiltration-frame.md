*Lightweight, agile exoskeleton for stealth, infiltration, and EW support.*

Favored by Spectres for quiet movement and system intrusion capabilities. Minimal armor, relies on stealth. Micro-servos aid Frame checks for agility. Ghostlink Interface enables Cyber Warfare using Systems, adding Mind 1 Binding when active.

**Effect:** Provides stealth movement, electronic warfare capability via high Systems, and signature dampening against detection. Piloting requires an installed Neural Link; the built-in Ghostlink Interface connects the frame to that implant and does not replace it. The frame does not include a Combat Deck.

The frame binds Ghost 3 in addition to the Neural Link’s Ghost 3. Activating Ghostlink adds Mind 1; access through the Neural Link makes this eligible for its shared Mind 8 software/systems allowance. Allocate that allowance across all systems using the link, counting each cost once. The frame’s separate Load Bearing (2 Any) supports directly attached equipment, not its own pilot Binding or the installed implant.

**Binding rationale:** Ghost 3 — managing stealth systems, sensor spoofing, EW suite, and agile maneuvering demands focus and predictive capability on top of the implant’s integration cost. Mind 1 additional when Ghostlink Interface is active.
